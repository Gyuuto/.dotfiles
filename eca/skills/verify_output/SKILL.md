# Verify Output — 出力値の検証スクリプト作成

プログラムやツールの出力（画像・バイナリ・テキスト等）が期待値と一致するか、許容誤差内にあるかを検証する Python スクリプトを生成する。

## Purpose

- 画像・バイナリ・数値出力の自動検証を可能にする
- リグレッションテストとして過去の出力と比較する仕組みを提供する
- 再現性のある検証プロセスを確立する

## Trigger

以下のいずれかに該当する場合に適用する：

- プログラムの出力（画像・バイナリ・数値）が期待値と一致するか確認したい場合
- リファクタリング前後で出力に差分がないか確認したい場合
- 数値計算の精度・誤差を検証したい場合
- ユーザが「この出力が正しいか確認して」と依頼した場合

## Steps

### 1. 検証対象の出力箇所を特定する

ユーザに以下を問い合わせる：

- 出力を生成しているコードの位置（ファイルパスと行番号）
- 出力ファイルのパス（既存の場合）
- 出力の取得方法（標準出力、ファイル書き出し、APIレスポンス、変数の値等）

取得できない場合は、対象のコードを読み込み、出力箇所を推定する。

### 2. 出力形式を推定する

対象の拡張子・処理内容から出力形式を特定する：

| 種別 | 判定方法 | 例 |
|------|---------|-----|
| 画像 | 拡張子（`.png`, `.jpg`, `.bmp`, `.tiff`）または PIL/Opencv 使用箇所 | レンダリング結果、プロット画像 |
| バイナリ | 拡張子（`.bin`, `.raw`, `.dat`）または `struct`/`numpy.tofile` 使用箇所 | 数値配列ダンプ、シリアライズデータ |
| テキスト | 拡張子（`.txt`, `.csv`, `.json`）または `print`/`write` 使用箇所 | ログ、CSV出力、JSONレスポンス |
| 数値（変数） | 計算結果の変数や配列 | 浮動小数点数、整数、ndarray |

形式が判然としない場合は、ユーザに確認する。

### 3. 比較方法を決定する

出力形式に応じて比較方法を選択する：

**画像の場合：**
- ピクセル完全一致（`numpy.array_equal`）
- 誤差許容比較（`numpy.allclose` — 数値化後）
- 構造的類似度（SSIM）
- ハッシュ比較（pHash, dHash, aHash）

**バイナリの場合：**
- バイト列完全一致（`==`）
- ハッシュ比較（MD5, SHA-256）
- 構造比較（ヘッダー・サイズ・特定オフセットの値）

**テキストの場合：**
- 完全一致（`==`）
- 正規表現マッチ
- 行ごとの比較（差分形式）
- JSON の場合は辞書比較（`==` またはキーごとの比較）

**数値の場合：**
- 完全一致（`==`）
- 絶対誤差（`abs(a - b) < atol`）
- 相対誤差（`abs(a - b) / abs(b) < rtol`）
- `numpy.allclose`（atol + rtol の組み合わせ）

### 4. 期待値を特定する

以下のいずれかの方法で期待値（ベースライン）を取得する：

- **既存ファイル**: 過去に保存された「正しい」出力ファイルを指定してもらう
- **コード内定数**: ソースコード内のリテラル値やアサーション
- **ユーザ入力**: 手動で期待値を入力してもらう
- **直前の実行結果**: 一時ファイルとして保存された出力

期待値がない場合は、現在の出力を「正解」として保存するかどうかをユーザに確認する。

### 5. ユーザに検証条件を確認する

比較方法と合わせて、以下を問い合わせる：

- **許容誤差**（数値・画像の場合）: atol, rtol, ピクセル差の閾値
- **除外領域**（画像の場合）: タイムスタンプ、ランダム要素、メタデータ等を除外する領域
- **比較対象外キー**（JSONの場合）: 実行ごとに変わる可能性のあるフィールド
- **サンプリング**（大容量バイナリの場合）: 先頭Nバイト・特定オフセット・等間隔サンプリング

### 6. Pythonスクリプトを生成する

上記の条件に基づき、検証用の Python スクリプトを生成する。

スクリプトの構成：

```python
import sys
import numpy as np
from PIL import Image
import hashlib

# --- 設定 ---
ACTUAL_PATH = "path/to/actual_output.png"
EXPECTED_PATH = "path/to/expected_output.png"
THRESHOLD = 1e-5  # 許容誤差

# --- 読み込み ---
def load_image(path):
    return np.array(Image.open(path))

actual = load_image(ACTUAL_PATH)
expected = load_image(EXPECTED_PATH)

# --- 検証 ---
def verify():
    if actual.shape != expected.shape:
        print(f"FAIL: Shape mismatch {actual.shape} vs {expected.shape}")
        return False
    
    diff = np.abs(actual.astype(float) - expected.astype(float))
    max_diff = np.max(diff)
    
    if max_diff > THRESHOLD:
        print(f"FAIL: Max difference {max_diff} exceeds threshold {THRESHOLD}")
        return False
    
    print(f"PASS: Max difference {max_diff} within threshold {THRESHOLD}")
    return True

if __name__ == "__main__":
    ok = verify()
    sys.exit(0 if ok else 1)
```

生成後、ファイルを保存する前にユーザに内容を確認してもらう。

### 7. スクリプトを実行し、結果を報告する

スクリプトを実行し、以下を報告する：

- **PASS**: 出力が期待値と一致（または誤差内）
- **FAIL**: 出力に差分あり。差分の詳細（最大誤差、差分箇所のヒートマップ等）を提示
- **ERROR**: スクリプト実行エラー。依存ライブラリの不足やパスの間違い等

FAIL の場合は、差分が許容範囲内か（閾値の調整）、実際にバグかをユーザと判断する。

## Output

### 検証用 Python スクリプト

ファイル名: `verify_output_<target_name>.py`

- 設定部分（パス、閾値）が冒頭に集約されている
- 読み込み・検証・レポートの関数に分離されている
- 終了コードで結果を伝える（0: PASS, 1: FAIL）

### 実行結果レポート

```
# 出力検証レポート

## 対象
- 実際の出力: <path>
- 期待値: <path>
- 形式: <画像/バイナリ/テキスト/数値>
- 比較方法: <完全一致/誤差許容/ハッシュ等>

## 結果
- ステータス: PASS / FAIL / ERROR
- 詳細: <最大誤差、差分箇所等>

## 差分の詳細（FAIL時）
<具体的な差分情報、ヒートマップのパス等>

## 次のアクション
- 閾値の調整が必要か
- 期待値の更新が必要か
- バグ修正が必要か
```

### 出力ルール

- スクリプトは単体で実行可能な完全なコードとする
- 必要なライブラリは import 文をコメントで明示する（`# pip install pillow numpy`）
- 画像差分の場合、差分ヒートマップをファイルとして保存するオプションを含める
- バイナリ比較の場合、差分オフセットを16進数で報告する
- 数値比較の場合、相対誤差と絶対誤差の両方を報告する
