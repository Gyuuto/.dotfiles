# Commit Message — コミットメッセージの生成とレビュー

コミットメッセージの生成と既存メッセージのレビューを行うスキルです。Conventional Commits に準拠した一貫したメッセージを確保します。

## Purpose

- コミットメッセージを自動生成し、一貫性と正確性を担保する
- 既存のコミットメッセージをレビューし、改善点を特定する
- Conventional Commits 仕様に準拠したメッセージ形式を強制する

## Trigger

- ユーザがコミットメッセージの生成またはレビューを要求した際
- 未コミットの変更がある状態でコミット準備が行われたとき
- コミット履歴の整理やメッセージ修正が必要なとき

## Steps

### コミットメッセージ生成

1. `git diff` で現在の変更を取得する
2. 変更内容の要約を把握する（何が変わったか）
3. 変更の種類を分類する（`feat`, `fix`, `refactor`, `docs`, `test`, `chore` など）
4. コミットメッセージを生成する:
   - 件名: 50文字以内で変更内容を簡潔に記述
   - 本文: 必要に応じて詳細を改行を挟んで記載
5. 生成したメッセージをユーザに提示し、確認を取る

### コミットメッセージレビュー

1. `git log` で履歴上のコミットメッセージを取得する
2. 各コミットメッセージを確認する:
   - 件名が変更内容を明確に表しているか
   - 適切な接頭辞（`feat`, `fix`, `refactor`等）を使用しているか
   - 必要十分な詳細が本文に記載されているか
   - 誤字脱字がないか
   - 一貫した文体か
3. 改善すべきコミットメッセージを特定し、修正案を提示する

## Output

- **生成されたコミットメッセージ**: 件名と本文から構成されるメッセージ
- **レビューレポート**: 改善すべきコミット番号、該当メッセージ、修正案のセット
